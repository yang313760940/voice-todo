# Issue #21 实施记录

## 实现

- `QuadrantScreen` 展示全部未完成事项，按 2×2 四象限排列。每项显示当前用户象限；AI 创建的事项额外显示“AI 建议：…（仅建议）”，该建议独立持久化，用户移动象限后仍保留原建议。
- 长按事项后拖动可跨象限移动；拖动过程中高亮目标象限，松手后落到目标分类。每个事项同时提供 48dp 的“移动到…”菜单，列出另外三个象限，作为不依赖拖拽的等价入口。
- 象限内排序由 `quadrantEntries` 统一定义：逾期最先，其次 24 小时内临近截止/提醒，最后其他；同组按最近有效时刻、创建时间与 id 稳定排序。
- `NEAR_WINDOW` 固定为 24 小时，只产生“逾期 / 临近截止 / 临近提醒”提示，不参与象限写入。`moveToQuadrant` 只更新 `quadrant`，不改变提醒、截止、计划日期、提醒修订号或清单归属，也不调用系统调度器。
- 待办页每个事项显示“象限：…”，与四象限页共享同一 `TodoViewModel` 与 Room 数据，移动后两页即时同步。
- `TodoItem` 新增可空 `suggestedQuadrant`；数据库版本升到 v5（`AutoMigration(4, 5)`），生成 `5.json`。旧版事项升级后建议为空，行为保持“手动默认不重要不紧急”。
- AI 草稿解析同时记录原始建议与用户可编辑分类；确认后 `quadrant` 为最终用户选择，`suggestedQuadrant` 仅用于展示。

## 验证

- `QuadrantRulesTest`（4 项）：移动只改分类且不重新调度；手动默认与 AI 建议分离；象限内逾期→临近→普通排序；临近只提示不改象限。
- `QuadrantScreenTest`（5 项）：菜单移动持久化并在待办页同步可见；长按拖拽跨象限；排序在真实 Compose 布局中的上下顺序；临近截止不自动迁移；深色主题、1.5 倍字体、720×400dp 宽屏布局下菜单移动仍可用。
- 全量证据轮次：JVM 28 个测试套件、129 项测试全部通过（0 失败、0 跳过），包含真实临时 Room 数据库与既有升级链（v1/v2 → v5）。
- `:app:lintDebug` 通过（0 error、27 warning，均为既有依赖版本/配置类提示，本轮文件无新增告警）；`:app:assembleDebug`、`:app:assembleDebugAndroidTest` 通过，生成 debug APK。

## 边界

- 验证基于 Robolectric/API 33 与 JVM 构建，没有真机验收；不代表跨厂商或真实旋转/系统字体设置验收。
- 旋转可用性以 720×400dp 约束布局模拟宽屏，未执行真实 Activity 重建。
- 拖拽只在当前可见的象限区域内生效，未实现拖到屏幕边缘时自动滚动；四象限页整体可纵向滚动。
- 不做统计图表、象限自动推荐重排或重复积压折叠（后者复用 #8）。
