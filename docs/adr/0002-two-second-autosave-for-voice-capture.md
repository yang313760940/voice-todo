# 语音事项填写完成后两秒自动保存

首版规格要求 AI 草稿经用户确认后才创建事项。本次改版面向个人高频录入，用户决定语音录入在填写完成后等待两秒自动保存，不再逐次点击确认；纯文字录入与完整手动表单仍需手动保存。

自动保存带来误存风险，因此配套四项约束：开始编辑草稿或识别文字、点击倒计时、关闭面板或切换 tab 均取消本次自动保存并转为手动保存；保存成功后五秒内提供整批撤销，恢复为草稿；明显无效日期、已过去的提醒时间、无法确定的时间表述会暂停整批自动保存；AI 整理失败、断网、转写失败及达到六十秒录音上限时一律改为手动保存，不自动重试。

被否定的替代方案是保留“确认后创建”，其速度不符合个人语音速记的使用场景；也没有选择“保存后只能删除、不提供撤销”，因为两秒窗口过短，缺少纠错机会会放大误存代价。

该决定改变了首版的安全模型，后续若面向多人协作或共享清单，应重新评估是否收紧为确认后保存，不能默认沿用个人场景的自动保存。
