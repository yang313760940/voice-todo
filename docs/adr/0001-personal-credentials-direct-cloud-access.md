# 个人凭据与手机直连云端服务

本次在线语音改版面向个人使用。用户已确认在“我的 → 语音与 AI”选择豆包或阿里云，提供自己的开发者 API 凭据，由手机直接调用同一家供应商的语音转写及事项整理接口，费用计入个人服务账号。相较于自建中转服务器，此方案无需额外部署维护服务，但需要用户自行开通云服务、配置凭据并承担调用费用。

凭据在手机本地加密保存，安装包不内置共享密钥；本次不建设持有统一密钥的服务端。两个阶段仍使用各自接口，不能假定同一供应商必然共用一个模型或一把密钥。此边界不授权删除既有自定义 AI 配置或用户数据。

该决定是已确认的设计边界。截至 2026-11-06，豆包实时转写适配器、设备加密配置与首次上传告知已落地，并使用个人凭据完成真实握手与静音识别冒烟；阿里云百炼适配器已实现实时转写与同一把 Key 的文本整理，假 WebSocket 与假文本服务测试通过，真实百炼服务联调仍待维护者完成；真机端到端验收尚未实现。本地加密不保证受控或被攻破设备上的凭据绝对安全，也不能替代供应商的云端隐私政策；应用的首次上传告知、上传范围及录音保留要求已记录于[需求访谈的隐私规则](../requirements-interview.md#已确认方向)，供应商实际数据保留条款及具体凭据配置仍需核实。若后续面向公众提供统一付费额度，应重新评估服务端鉴权和额度管理，不将个人直连方案直接改为安装包内共享密钥。
