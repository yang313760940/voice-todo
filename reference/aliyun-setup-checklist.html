百炼接入：一页速查

适用于本 App 当前的阿里云设置界面；不收集或保存密钥。

获取

百炼控制台 API Key 页面 → 华北2（北京） → 创建 API Key → 自己的账号、默认业务空间 → 复制。

需要百炼 API Key，不是登录密码，也不是 AccessKey ID / Secret。Key、接口地域与模型权限须匹配；一把拥有对应权限的 Key 可以访问转写与整理两个模型。

手机填写

我的 → 语音与 AI → 语音与 AI 设置

字段内容
供应商 / 语言阿里云 / 普通话
百炼 API Key自己的真实密钥，只在手机设置里粘贴
百炼文本模型qwen-plus
保存按钮保存语音与 AI 配置

语音模型由此版默认使用 qwen3-asr-flash-realtime，服务地址无需在界面中填写。“旧配置”不参与语音添加。

验收

联网 → 麦克风 → 阅读上传提示 → 说“明天下午三点提醒我买牛奶” → 结束 → 检查转写、标题、提醒时间。想检查草稿时，点击倒计时取消自动保存。

已配置 ≠ 调用成功。转写与整理都得到正确结果，才验证了两段服务。

安全与费用

不要发送、截图或提交 Key；使用独立测试 Key 并限制权限。调用可能收费，请先查看额度和账单。手机端长期 Key 仍有风险，官方推荐客户端使用临时 Key；测试后可删除测试专用 Key。
