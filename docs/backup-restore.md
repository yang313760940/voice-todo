# 备份与恢复（v1）

入口：`我的 → 数据管理`。

## 备份内容

备份是一个 JSON 文件，格式标记为 `voice-todo-backup`、`formatVersion = 1`，包含：

- 事项（含重复安排模板、重复实例、提醒、象限、清单归属与完成状态）
- 自建清单
- 专注历史（阶段、时长、状态与关联事项 id）
- 番茄时长设置
- 外观偏好（主题、字体大小）

明确不写入备份：

- 录音（应用本身不长期保留录音）
- AI 服务配置与其密钥（密钥由 Android Keystore 保护）
- 通知、精确闹钟、麦克风等权限授权

## 导入行为

1. 选择文件后先解析并展示格式版本、导出时间和数量；不会在这一步改动数据。
2. 用户确认后，在应用私有目录 `files/backups/` 生成当前数据的恢复副本。
3. 保存新偏好，取消旧事项与旧番茄调度。
4. 在一个 Room 事务中替换事项、清单、专注记录与番茄设置。
5. 按新数据对账并重建未来提醒；过去提醒只保留为漏做记录，不自动补响。

损坏 JSON、字段非法、id 重复、清单或重复安排引用断裂、版本高于当前支持版本时整份拒收，原数据不变。

备份中的运行中/暂停中番茄会话会被冻结为已结束的历史记录（保留累计时长），恢复后不会自动走秒，用户可以手动开始新的番茄。

## 恢复副本

每次替换导入前自动生成 `restore-YYYYMMDD-HHmmss-SSS.json`。恢复副本保留在应用私有目录，可在数据管理页直接预览并再次导入；它和普通备份使用同一格式与校验规则。

首版只做替换，不做合并导入、自动云备份或跨设备同步。
