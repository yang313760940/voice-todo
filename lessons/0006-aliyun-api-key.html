让手机接上阿里云百炼

一个小胜利：自己获取密钥、填入设置，并用一句话验证云端链路。

这一课属于“AI 写代码，我做决策与验收”：不改代码、不重装 APK，由你完成账号授权与真机测试。步骤可随时暂停。

先保护密钥 不要把 API Key 发到聊天、截图、课程文件或 GitHub。 只在百炼控制台复制，再粘贴到自己的手机应用。课程不收集、不保存密钥。 调用可能产生费用，先查看控制台额度与账单规则，不必为了完成本课购买订阅。

先懂一句话

API Key（接口密钥）是 App 调用云服务时出示的秘密凭证，类似专用通行证，不是登录密码。这里要的是阿里云百炼 API Key，不是 AccessKey ID / AccessKey Secret。

本 App 的链路是：录音 → 语音转写 → 文字整理 → 事项草稿。阿里云供应商使用同一把百炼 Key 访问两种模型，前提是该 Key 拥有对应模型权限。

一 · 获取正确的 Key

  1. 在手机浏览器打开百炼 API Key 页面并登录。手机操作便于稍后直接复制到 App；网页难操作时可在电脑上完成。登录验证码、实名认证与服务开通由你本人处理。
  2. 检查地域是华北2（北京）。本 APK 默认使用北京接口；不要选新加坡或美国。地域是服务接入区域，不是手机所在地。
  3. 点创建 API Key。个人初次使用：归属账号选自己的主账号，归属业务空间选默认业务空间。若有权限选项，测试专用 Key 可限制为本课的两个模型；若界面不便设置，官方流程允许“全部”，但不要将这把 Key 分享给别人。
  4. 确认创建后使用复制按钮。只复制完整密钥，不加引号，不在前后附带空格；不要手抄，也不要把示例文本当作真实密钥。

依据：阿里云官方获取与配置 API Key。若你看到的界面不同，停在当前步骤，告诉老师页面文字；发截图前必须遮住密钥。

App 的“百炼 API Key”应该填什么？

二 · 填入小米 12X 上的 App

路径：我的 → 语音与 AI → 语音与 AI 设置。

设置项填写内容
供应商阿里云
识别语言普通话
百炼 API Key你刚复制的真实密钥，由你自己粘贴
百炼文本模型qwen-plus（保留默认值）
  1. 选“阿里云”，再选“普通话”。
  2. 把密钥粘贴进“百炼 API Key”；文本模型保留 qwen-plus。
  3. 点保存语音与 AI 配置，确认出现配置已保存的提示，以及“语音识别：已配置”“事项整理：已配置”。

这版不需要你填服务地址或语音模型；实时识别默认使用 qwen3-asr-flash-realtime。不要把配置填进下方“旧配置（仅查看，不参与语音添加）”。

安全边界 保存到自己手机的设置，不等于把密钥写进 APK 源码。 但手机端长期密钥仍有泄露风险：阿里云建议客户端避免使用长期 Key。 本课仅针对你自己的测试手机，优先使用独立测试 Key、限制模型权限，测试结束后可在控制台删除这把 Key。

三 · 验收，不只看“已配置”

  1. 手机保持联网，回到待办页面，点击底部麦克风。
  2. 若出现麦克风权限或“录音和文字将上传到阿里云”提示，阅读后由你决定是否允许；接受上传时点“同意并开始”。不要用真实隐私内容测试。
  3. 说：“明天下午三点提醒我买牛奶。”然后结束录音。
  4. 检查两个结果：① 转写文字大意正确；② 草稿标题与提醒时间正确。若想先检查，点倒计时取消自动保存；检查后手动确认。正常不操作时，这版会在倒计时结束后自动保存。

只有“说话能转写、文字能整理”的实际结果，才验证了两段云服务。配置已保存只说明本地接受了输入，不证明密钥有效或有额度。

哪种证据能检验 Key 是否真的可用？

卡住时，只报告现象

找不到创建按钮：检查是否登录正确账号，以及是否有管理权限。鉴权失败：核对北京地域、完整 Key 与模型权限。额度或欠费提示：查看控制台，不要反复充值试错。转写成功但整理失败：分别报告两个阶段，不要把它们当作同一个故障。

这些是排查方向，不是对你手机的诊断结论。告诉老师错误文字与发生步骤即可，不要发送密钥。
